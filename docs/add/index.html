Список исключений OpenToConnect

    Открыть в OpenToConnect

    Программа покажет список и спросит подтверждение. Если ссылка не открылась, скопируйте код и вставьте его кнопкой «Вставить списком» на вкладке «Исключения».

    Адреса из списка пойдут напрямую, мимо туннеля. Добавляйте списки только от тех, кому доверяете.

    Список хранится в самой ссылке (после знака #) и не передаётся на сервер. Скачать OpenToConnect · Описание
