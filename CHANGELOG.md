# История изменений

## 0.8.3

- Выбор из запущенных: по умолчанию только приложения с окнами (вместо всех процессов), галочка «Показать фоновые» — для программ в области уведомлений. Службы и чужие сеансы не показываются.
- Подсказка «лучше добавить папку», если из той же установки запущено несколько программ; кнопка «Её папку» добавляет их общую папку (например, `Steam\` вместо папки `steamwebhelper.exe`).

## 0.8.2

- Программу для исключения можно выбрать из запущенных: «Добавить программу» → «Из запущенных…». Список с поиском, значками и путями; добавляется сама программа или её папка.

## 0.8.1

- Проверка новых версий: при запуске окна и раз в 12 часов. Если вышла новая версия, справа от надписи состояния появляется значок; по нажатию программа скачивает установщик, сверяет SHA-256 и запускает обновление.

## 0.8.0

- **Исключения по программам и папкам.** В список можно добавить `C:\...\app.exe` или папку `C:\...\` — кнопкой «Добавить программу» или вводом пути. Служба узнаёт адреса, к которым обращаются эти программы, из событий ядра Windows (ETW) и ставит на них маршруты мимо туннеля. Адреса хранятся 7 дней с последнего использования и сохраняются между перезапусками.
- «#» считается комментарием только в начале строки или после пробела, чтобы пути вроде `C:\Games\C#\` не обрезались.

## 0.7.2

- Обновлены зависимости (предложения Dependabot): `Microsoft.Extensions.Hosting` 10.0.13, `System.Security.Cryptography.ProtectedData` 10.0.13, тестовые пакеты и действия GitHub Actions. Поведение программы не меняется.

## 0.7.1

- Иконка у ярлыка в меню «Пуск», у закреплённой кнопки на панели задач и в списке «Приложения». Ярлык, который создаёт MSI, объявленный (advertised) и берёт иконку только из таблицы Icon пакета, а её там не было.
- Dependabot: еженедельные предложения обновлений зависимостей (GitHub Actions, NuGet).

## 0.7.0

Первая публичная версия.

- Подключение по логину и паролю к серверам, совместимым с OpenConnect; служба Windows, окно без прав администратора, автоматическое переподключение.
- Исключения из туннеля: IP-адреса, подсети, домены и маски `*.domain`, с адресами из журнала DNS-клиента Windows; применяются сразу.
- Настройка сети туннеля собственным помощником через IP Helper API, без Windows Script Host.
- DNS этого компьютера по умолчанию, DNS сервера — по выбору.
- Компактное окно, значок в области уведомлений, тема по системе, установка одним MSI.
- Сохранённый пароль сбрасывается при смене сервера, логина, протокола или отпечатка сертификата.
- Файл сторонних лицензий; версии и лицензии библиотек OpenConnect включаются в установщик.
