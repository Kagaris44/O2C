# Безопасность

- Права администратора нужны только при установке. Всё, что их требует (адаптер, маршруты, DNS), делает служба; окно работает с правами пользователя.
- Пароль хранится в `C:\ProgramData\OpenToConnect\settings.json`, зашифрованный DPAPI; папка доступна только SYSTEM и администраторам. В openconnect пароль передаётся через стандартный ввод и не виден в списке процессов.
- **Сохранённый пароль сбрасывается**, если в настройках изменились сервер, логин, протокол или отпечаток сертификата. Иначе другой пользователь компьютера мог бы направить сохранённый пароль на свой сервер.
- Окно и служба общаются через именованный канал `\\.\pipe\O2C.Control`. Доступ — только локальным вошедшим пользователям, из сети — запрещён. Перед отправкой пароля окно проверяет, что на том конце служба: сервер канала работает в сессии 0, владелец канала — SYSTEM или администраторы.
- Любой вошедший пользователь компьютера может подключать и отключать туннель и править список исключений. Если туннель — обязательное требование вашей организации, учтите это.
- Пока есть подключение и в исключениях есть программы или запись `@ru`, служба держит сеанс событий ядра `O2C-AppConnections` (ETW): она видит, какие программы компьютера к каким адресам подключаются, но запоминает только адреса программ из списка и российские подсети, к которым было обращение (`ru-networks-seen.json`, 7 дней). Сеанс закрывается при отключении.
- С записью `@ru` служба раз в сутки скачивает список российских подсетей `ru-networks.txt` из последнего релиза этого репозитория (без сведений о компьютере). Файл проверяется на формат и размер; при сбое используется прежний или вложенный в установщик.
- Пока есть подключение и в исключениях есть домены, включён журнал DNS-клиента Windows (`Microsoft-Windows-DNS-Client/Operational`). В нём фиксируются DNS-запросы компьютера; читать журнал могут администраторы. После отключения служба выключает журнал, если включала его сама.
- Все загрузки при сборке (исходники OpenConnect, Wintun) проверяются по SHA-256.
- Проверка обновлений — один запрос к `api.github.com` (последний релиз репозитория `Kagaris44/O2C`) без сведений о компьютере и подключении. Автоматическую проверку можно выключить в настройках; тогда окно обращается к GitHub только по кнопке «Проверить обновления». Установщик скачивается только по ссылке из этого репозитория и только после подтверждения; при несовпадении SHA-256 установка отменяется.

## Как сообщить об уязвимости

О найденных уязвимостях пишите через [Security Advisories](https://github.com/Kagaris44/O2C/security/advisories/new) репозитория, а не в открытые Issues.
